Знайдіть кореневу вершину графа
Коренева вершина орієнтованого графа — це вершина u з орієнтованим
шляхом від u до v для кожної пари вершин (u, v) у графі. Іншими словами, всі
інші вершини в графі можна досягнути з кореневої вершини (Рис. 2)
Граф може мати кілька кореневих вершин. Наприклад, кожна вершина графу
може бути мати зв’язки з іншими (Рис.1). У таких випадках ваш код має
повернути будь-яку із них. Якщо граф не має кореневих вершин, код має
повернути -1.
Для представлення графу слід використати список суміжності, який
зчитується з файлу input.txt
Результат слід вивести у файл output.txt
